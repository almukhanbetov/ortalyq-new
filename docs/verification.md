# Проверки

## Backend — `go test ./...`

Unit:
- оценивание (`attempts/grade_test.go`): подсчёт верных, неверных и пустых ответов, баллы, детерминированность, точное совпадение множеств при множественном выборе, учёт только проверенных ответов в режиме instant, скрытие ключа без изменения оригинала;
- валидация теста (`exercises/test_kind_test.go`): пустой вопрос, один вариант, нет правильного, два правильных при одиночном выборе, пустой вариант.

Интеграционные (`internal/router/integration_test.go`, настоящий PostgreSQL, отдельные cookie-сессии для каждого пользователя):

| Сценарий / свойство | Проверка |
|---|---|
| Роли | не-админ получает 403 на `/admin`; преподаватель не может создать класс с неназначенным ему учеником |
| Материалы | создание, переименование, порядок (неполный список отклоняется), фильтр по навыкам и уровню |
| Ключ ответов | в ответе API ученику нет `is_correct` до раскрытия |
| Instant-проверка | старт идемпотентен; повтор проверенного ответа идемпотентен; изменение проверенного ответа → 409; чужой ученик → 404 |
| After-режим | результат и ключ скрыты до завершения; `check` запрещён |
| Таймер | повторный старт не меняет срок; ответ после срока → 409; при чтении попытка завершается с `timeout`, `finished_at = deadline` |
| Версии | правка упражнения не меняет вопрос в завершённой попытке |
| Баллы | 1/1 в категории «Универсальная» после повторных `finish` |
| Изоляция | тот же урок в другом классе без попыток и завершения; ученик не видит чужой класс и чужие ответы; преподаватель не видит чужой класс |
| Сброс | касается только выбранного ученика, старая попытка остаётся в аудите |
| ДЗ | копия упражнения независима; submit → pending (идемпотентно); ответы заблокированы; revision → правка → submit №2; снимок №1 не изменился; устаревший `from_status` → 409; done; 4 события с автором; завершение до отправки |
| Завершение | раздел, урок без оценки → 422; ученик не может завершить → 403; смена оценки; отмена; статусы урока и ДЗ независимы |
| Чат | повтор `client_id` → то же сообщение; чужое сообщение нельзя править или удалять; правка и удаление приходят по WebSocket; история без удалённых |
| WebSocket | не-член класса → 404, аноним → 401 |
| GIF | без ключа → 503; с подменённым GIPHY: поиск, отправка с подписью, правка и очистка подписи, неизвестный или некорректный id отклоняется |
| Вложения | PNG принят; HTML отклонён; загрузка и скачивание не-членом → 404; файл удалённого сообщения недоступен |
| Вход | 6-я неудачная попытка → 429; logout завершает сессию; чужой Origin → 403; cookie `HttpOnly` + `SameSite=Lax` |

Миграции: на чистой БД проверены `migrate up`, `migrate reset` и снова `up`; тесты каждый раз пересоздают схему.

## E2E в браузере — `frontend/scripts/e2e.mjs`

Две отдельные сессии Chrome (преподаватель и ученик). Прогон выполнялся и на локальных процессах, и на стеке `docker compose`:

1. Преподаватель создаёт тест (с проверкой валидации), домашний тест и тест с таймером (30 с, с вопросом множественного выбора).
2. Открывает урок в классе через «Другой урок» и проверяет фильтр.
3. Ученик проходит тест, результат и баллы 1/1 сохраняются после обновления. В HTML страницы нет ключа.
4. Тест с таймером: экран запуска, отсчёт, обновление страницы не сбрасывает время (30 → 26 с), автоматическое завершение по истечении.
5. Преподаватель видит ответ ученика только для просмотра: на вариантах нет кнопок.
6. ДЗ: отправка → доработка (приходит ученику в реальном времени) → исправление → повторная отправка (№2) → принятие → зелёное уведомление у ученика.
7. Отметка раздела, завершение урока с оценкой «Удивительно». Ученик видит оценку и не видит «Отменить завершение».
8. Чат в обе стороны, правка и удаление синхронизируются, история после перезагрузки без дублей.
9. Загрузка картинки, скачивание с `Content-Disposition: attachment`, отказ для HTML.
10. Обрыв сети у ученика: баннер «Переподключение…», пропущенное сообщение появляется после восстановления, без дублей.
11. Скриншоты при 1440×900 и 390×844, ошибок в консоли браузера нет.

## Левое меню — `frontend/scripts/sidebar-check.mjs`

- Начальное состояние — 64 px, подписи скрыты.
- Наведение: 240 px, подписи видны, отступ контента не меняется (наложение). Переходы между всеми пунктами и пустой областью панели меню не закрывают.
- Уход курсора: через 90 мс панель ещё открыта, затем сворачивается. Быстрый выход и возврат в пределах задержки не закрывают.
- Клик мышью по пункту и уход курсора: панель сворачивается (фокус после клика её не удерживает).
- Закрепление: панель не сворачивается, контент сдвигается, состояние сохраняется после перезагрузки. После открепления снова работает раскрытие при наведении.
- Клавиатура: Tab в шапке панель не раскрывает; фокус на пункте раскрывает; при переходах Tab внутри панель остаётся открытой; когда фокус уходит — сворачивается.
- Мобильная версия 390 px: панель открывается кнопкой поверх контента, закрывается тапом вне неё.

## Панель инструментов класса — `frontend/scripts/classroom-toolbar-check.mjs`

Данные не меняются: сообщения не отправляются, ответы не трогаются. Для преподавателя и для ученика проверен сценарий «Классы» → «Войти в класс»:

- повторное наведение, закрытие чата и инструмент «Разделы» работают через прежние обработчики;
- клавиатура: Tab раскрывает панель, при уходе фокуса она сворачивается;
